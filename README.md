# pair-wise-yf-54 博物馆展品点交与布展条件核验

## 源提示词摘要
策展人、保管员、布展负责人和借展方从到场点交、环境条件检查、安装位置确认到闭展归还共同处理展品。系统记录条件、附件、风险等级、照片说明、处理意见和签字结果，差异项未解决时不能进入下一阶段，并支持大量展品与断网暂存。

## 本轮业务规则（已全部实现）
- **分头核验、各签各的，越权代签一律拒绝**
  - 保管员只能确认包装封条（封条编号 / 包装状态 / 附件清单）。
  - 布展负责人只能确认环境条件（温度 / 湿度 / 照度）。
  - 借展方只能确认差异处理意见；没有借展方意见的差异不能解决。
  - 顶栏可切换当前操作身份，非本人职责的写入/签字会被规则拒绝并提示。
- **签字即冻结事实快照**：每条签字带 FNV 指纹快照（封条/包装/附件/环境/位置），界面展示签字人与快照号。
- **快照失效 → 退回待复核 → 原角色再确认**
  - 环境条件（温/湿/照度）更新、展品位置更新都会使旧签字快照失效（旧签保留留痕、不删除）。
  - 展品置为「待复核」，只有原角色按各自维度重新签字后才能继续推进。
- **阶段门禁**：当前阶段三方有效签字齐全且无未解决差异，才能从到场点交 → 布展核验 → 闭展归还；到场点交结束时冻结到场快照作为对账基准。
- **闭展归还逐项对账**：归还登记与到场点交快照就封条编号、包装状态、附件清单、展品位置四项逐项比对（温/湿/照度为调控项不参与）；差异自动落成归还阶段差异项，并沿用该展品同项历史「原处理意见」，缺意见的差异留待借展方补充确认。
- **旧数据升级读回**：localStorage 中 v1 结构（`signed: ['保管员','借展方']` + 扁平差异）加载时自动迁移为 v2 带快照签字，未知角色忽略，已过到场点交阶段的展品补建对账基准快照。

## 技术栈
Vue 3 + TypeScript + Vite + Vuetify + Pinia + Vue Router + Axios + VueUse + VeeValidate + Zod + Vue I18n；规则测试使用 Vitest + happy-dom。

## 已实现闭环
- 展品、环境检查、差异项三类业务对象（差异已归入展品并区分发生阶段）。
- 到场点交、布展核验、闭展归还的分角色签字、快照失效、待复核与推进门禁。
- 未解决差异阻断流转，由借展方确认处理意见后单独解决。
- 闭展归还「归还登记 × 到场快照」逐项对账，差异落项并保留原处理意见。
- `v-virtual-scroll` 大列表、离线队列提示、手动确认同步。
- localStorage 持久化 + v1→v2 自动迁移。
- 18 条 Vitest 规则测试覆盖权限边界、快照失效/补签、对账与迁移。
